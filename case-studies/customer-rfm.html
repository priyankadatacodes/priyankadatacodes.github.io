Customer RFM Segmentation & CLV Analysis

Customer value segmentation and lifetime value analysis using SQL, Python, and Power BI

← Back to Portfolio

Executive Summary

This project performs end-to-end customer segmentation using the RFM (Recency, Frequency, Monetary) framework enriched with Customer Lifetime Value (CLV) analysis. The objective is to help businesses identify high-value, loyal, potential, at-risk, and churned customers, enabling focused retention and marketing strategies.

Why I Built This Project

Many businesses treat all customers the same without understanding who drives revenue, who is loyal, and who is at risk of churn. This project demonstrates how data-driven segmentation directly supports smarter retention, targeting, and growth decisions.

Business Context

  • Customer acquisition is expensive; retention is more cost-effective.
  • Not all customers contribute equally to revenue.
  • Marketing spend must be focused on high-value segments.
  • Early churn identification helps protect future revenue.

Problem Statement

Analyze transactional customer data to segment customers using Recency, Frequency, and Monetary metrics, enrich the segmentation with Customer Lifetime Value, and generate actionable insights for retention and marketing efficiency.

Dataset Overview

Retail transactional dataset containing customer-level purchase history used to calculate RFM scores, customer segments, and lifetime value metrics.

Tools Used

SQL (MySQL) · Python (Pandas, NumPy) · Power BI · Jupyter Notebook

Analysis Approach

  • Cleaned and validated transactional data using Python
  • Calculated RFM metrics and segmentation using SQL
  • Computed Customer Lifetime Value in Python
  • Built Power BI dashboards for business reporting

Key KPIs Tracked

  • Recency Score
  • Frequency Score
  • Monetary Score
  • Customer Segment
  • Customer Lifetime Value (CLV)

Key Insights

  • Champions and loyal customers generate the majority of revenue.
  • Lost customers form a large segment but contribute minimal value.
  • Potential customers show high future value based on CLV.
  • Many customers show low recency, indicating retention challenges.

Business Impact

  • Enables targeted marketing instead of mass campaigns.
  • Helps reduce churn by identifying at-risk customers early.
  • Optimizes marketing spend by focusing on high-value segments.
  • Improves retention and customer lifetime value.
