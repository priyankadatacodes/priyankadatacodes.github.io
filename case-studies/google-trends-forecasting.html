Google Trends Time Series Forecasting

End-to-end forecasting of search interest using Python, Prophet, and Streamlit

← Back to Portfolio

Executive Summary

This project performs time series forecasting on Google Trends data to analyze and predict interest patterns for high-demand technology keywords such as Data Analytics, Machine Learning, and Artificial Intelligence. Using dynamically fetched Google Trends data and Facebook Prophet, the project forecasts future interest while accounting for trend, seasonality, and noise.

Why I Built This Project

Search trends reflect real-world demand and interest, but most analyses stop at historical reporting. I built this project to practice predictive analytics and demonstrate how forecasting can support market research, content planning, and demand analysis.

Business / Analytical Context

  • Search trends help identify rising and declining topics.
  • Forecasting enables early decision-making instead of reactive planning.
  • Demand prediction supports marketing and content strategies.

Problem Statement

Analyze Google search interest data and forecast future trends for key technology topics, enabling data-driven decisions for marketing, content strategy, and skill demand planning.

Data Source & Dataset Overview

Data is dynamically fetched from Google Trends using the Pytrends API. The dataset includes daily search interest values for selected keywords over the most recent six-month period.

Tools & Technologies

Python · Pytrends · Prophet · Pandas · NumPy · Plotly · Streamlit

Analysis & Modeling Approach

  • Fetched Google Trends data dynamically using Pytrends
  • Cleaned and prepared time series data
  • Applied Prophet model to capture trend and seasonality
  • Evaluated forecast performance using RMSE
  • Deployed interactive results using Streamlit

Key Insights

  • Search interest varies significantly across keywords.
  • Artificial Intelligence shows stronger upward momentum.
  • Seasonal patterns are visible even in short-term data.
  • Forecasting highlights trend changes before they become obvious.

Business Impact

  • Supports content and campaign planning.
  • Helps identify emerging skills and topics early.
  • Demonstrates predictive analytics beyond static dashboards.
