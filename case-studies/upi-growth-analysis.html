Digital Payments (UPI) Growth & Adoption Analysis

Growth, adoption, and seasonality analysis of UPI transactions using Python, SQL, and Tableau

← Back to Customer Analytics

Executive Summary

This project analyzes UPI (Unified Payments Interface) transaction data to understand how digital payments have grown over time. Python was used for data cleaning, MySQL for SQL analysis, and Tableau for dashboard creation. The dashboard highlights transaction growth, adoption by banks, and seasonal trends.

Why I Built This Project

UPI is one of the most widely used digital payment systems in India. I built this project to practice real-world data analyst skills and understand how digital payment systems grow, scale, and evolve over time.

Business Context

  • Banks and fintech companies rely on digital payment growth.
  • Understanding trends helps in capacity and system planning.
  • Raw transaction data needs analysis to support decisions.

Problem Statement

Analyze UPI transaction data to measure growth, understand usage behavior, track bank adoption, identify seasonal patterns, and present insights using a simple and clear dashboard.

Dataset Overview

Monthly aggregated UPI transaction dataset containing transaction volume, transaction value, average transaction value, and number of banks live on UPI. The dataset does not contain user-level information.

Tools Used

Python · Pandas · NumPy · MySQL · SQLAlchemy · Tableau

Analysis Approach

  • Loaded and cleaned data using Python
  • Converted month fields into date format
  • Calculated KPIs and trends using SQL
  • Analyzed growth, adoption, and seasonality
  • Built a one-page Tableau dashboard

Key KPIs Tracked

  • Total UPI Transaction Volume
  • Total UPI Transaction Value
  • Average Transaction Value
  • Latest Month Transaction Volume
  • Number of Banks Live on UPI

Key Insights

  • UPI transaction volume has increased steadily over time.
  • Average transaction value remains mostly stable.
  • More banks are joining the UPI ecosystem every year.
  • Certain months show higher transaction activity.

Business Impact

  • Helps understand the scale and growth of digital payments.
  • Supports planning for system capacity and infrastructure.
  • Makes complex transaction data easy for business teams to understand.
